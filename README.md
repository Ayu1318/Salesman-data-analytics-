SALES PERFOMANCE DASHBOARD

This project focuses on analyzing a raw and unclean Salesman Dataset using Microsoft Excel and Power BI.
The dataset was first cleaned and organized in Excel by handling missing values, duplicates, and inconsistent data. The cleaned data was then imported into Power BI to create an interactive dashboard for analyzing sales performance.

🛠️ Tools Used
Microsoft Excel – Data cleaning and preprocessing
Power BI – Data visualization and dashboard creation
🔄 Project Workflow
Collected the raw salesman dataset.
Identified and handled missing and incorrect data.
Removed duplicate records and inconsistencies.
Organized and prepared the dataset using Excel.
Imported the cleaned dataset into Power BI.
Created interactive charts, KPIs, and filters.
Analyzed salesman performance and overall sales trends.

📊 DASHBOARD
The Power BI dashboard provides an interactive view of sales performance and helps identify important trends and insights from the dataset.
